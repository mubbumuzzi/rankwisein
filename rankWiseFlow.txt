Build a production-ready web application called RankWise.

# ====================================================
PROJECT VISION

RankWise is a personalized TS EAMCET counselling platform.

Students enter

- Rank
- Category
- Gender
- Preferred Branches

The system analyzes historical cutoff data and returns

1. Dream Colleges
2. Target Colleges
3. Safe Colleges

The goal is not just cutoff lookup.

The goal is to help students make better counselling decisions.
