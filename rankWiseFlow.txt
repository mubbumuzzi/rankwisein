# ====================================================
# PROJECT VISION
# ====================================================

RankWise is a personalized TS/TG EAPCET (EAMCET) counselling platform.

Students provide:
- Rank
- Category
- Gender
- Preferred branches
- Counselling year and phase (cutoff dataset to use)

The system analyzes historical cutoff data and returns:
1. Dream colleges (stretch — closing rank better than yours)
2. Target colleges (close match to your rank)
3. Safe colleges (higher closing ranks — more comfortable admits)

Goals beyond lookup:
- Lead capture for follow-up counselling
- AI counsellor chat (FAQ RAG + structured college cards)
- WhatsApp community / counselling CTAs
- Admin PDF import of official TG EAPCET cutoff PDFs

# ====================================================
# RECOMMENDATION ENGINE (PredictService)
# ====================================================

Input
  rank, category, gender, preferredBranches[], year, phase

Steps
  1. Normalize gender (MALE/M → BOYS, FEMALE/F → GIRLS)
  2. Log student_search (IP from X-Forwarded-For or remote)
  3. Query cutoffs: category + gender + branches + year + phase
  4. For each cutoff with closing_rank > 0:
       ratio = studentRank / closingRank
       (lower rank number = better student performance)
  5. Classify bucket:
       ratio <= 0.90  → SAFE   (closing rank well above yours)
       ratio <= 1.10  → TARGET (close match)
       ratio >  1.10  → DREAM  (stretch — better closing rank than yours)
  6. Sort base list: preferred branch first, then closing_rank, then college name
  7. Cap lists: Dream 30, Target 30, Safe 10
  8. Re-sort within bucket (dream = hardest first; target = closest to 1.0 ratio; safe = best safe options first)

Response (PredictResponse)
  rank, category, gender, year, phase
  dream[], target[], safe[] — each CollegeRecommendation with bucket badge

Result card fields
  college code/name, branch code/name, closing_rank, category, gender, year, phase, ratio, preferredBranch flag

# STUDENT FLOW — AI counselling chatbot
# ====================================================

Floating widget on most pages (counselling-chatbot).

Session
  POST /api/chat/sessions          — creates chat_user + session; returns sessionId + visitorToken
  Header on subsequent calls: X-Visitor-Token

Messages
  POST /api/chat/sessions/{id}/messages
  GET  /api/chat/sessions/{id}/messages

Profile (for personalized predictions in chat)
  PUT /api/chat/sessions/{id}/profile
  — rank, category, gender, preferredBranches, location, budget

Analytics
  POST /api/chat/sessions/{id}/events  — e.g. WhatsApp CTA clicks

Suggested prompts
  GET /api/chat/suggested-questions

Processing (ChatCounsellorService)
  1. Sanitize input, rate-limit, save user message
  2. ChatIntentDetector — rank regex, compare colleges, documents, branch advice, prediction, counselling guide
  3. Update profile if rank detected in message
  4. Build structured payloads when intent matches:
       DOCUMENTS, BRANCH_ADVICE, COMPARISON, PREDICTION (uses same bucket logic via ChatCollegeContextService)
  5. FAQ RAG retrieval (ChatRagService)
  6. Cursor Cloud Agent when configured (multi-turn via cursor_agent_id on session)
  7. Save assistant message + structured_json for UI panels

Chat links to predictor
  — "Check colleges" opens CheckCollegesLauncherService modal → /results

# ====================================================
# ADMIN FLOW — PDF import
# ====================================================

UI: /admin/import

Step 1 — Upload
  POST /api/admin/imports/pdf
  multipart: file + year + phase
  → PdfImportService: PDFBox text extract → TgEapcetPdfParser
  → Rows staged in import_staging_row (not yet in cutoff)

Step 2 — Preview staging
  GET /api/admin/imports/{importId}/staging?page=&size=
  UI: search/filter invalid & duplicate rows
  DELETE /api/admin/imports/{importId}/staging/{rowId}  — remove bad row

Step 3 — Approve
  POST /api/admin/imports/{importId}/approve
  → Batch insert into cutoff (JdbcTemplate, batch size 1000)
  → Upsert colleges/branches as needed
  → Summary: imported count, duplicates skipped, duration

Maintenance
  POST /api/admin/imports/repair-college-names
  — Re-parse stored PDFs to fix truncated college names

Danger zone
  POST /api/admin/cutoffs/purge?year=&phase=
  — Deletes all cutoff rows for year+phase

# ====================================================
# TG EAPCET PDF — Parser rules (deterministic)
# ====================================================

DO NOT USE: AI parsing, OCR, LLM for import.

PDF row columns (per institute line):
  Institute code, name, branch code/name
  OC_BOYS, OC_GIRLS, BC_A_BOYS, BC_A_GIRLS, … SC/ST/EWS variants

Normalization
  Each category × gender cell → one cutoff row:
    college, branch, category (OC, BC-A, SC-I, …), gender (BOYS/GIRLS), closing_rank

Ignore
  Page numbers, headers, footers, repeated column headers

Validation (staging)
  Missing codes, invalid/negative rank, duplicate (year+phase+college+branch+category+gender)
